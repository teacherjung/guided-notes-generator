# guided-notes-generator

把任何教材（影片逐字稿、書籍章節）自動轉成「不簡單」風格的**引導式筆記**：
T 版（完整筆記）＋ S 版（挖空工作簿），同構雙 PDF。

**品牌歸屬**：不簡單・學習神殿的「平台」格。
**定位一句話**：別人的 AI 筆記工具幫你「不用讀」（摘要），我們讓你「非寫不可」（挖空）——反摘要。
